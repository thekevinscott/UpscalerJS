# Contributing

Models, bug reports, feature requests, and discussions are welcome. PRs and core code contributions are not.

AI usage is permitted but must be explicitly marked. I build UpscalerJS with extensive AI assistance as disclosed in [AI.md](./AI.md).

## What's welcome

- **Models** are welcome. Your model lives in your own repository and conforms to the plugin interface; it is not hosted in this repo. Models can be listed in the official docs. A detailed guide to model contributions is forthcoming.
- **Bug reports.** File them [here](https://github.com/thekevinscott/UpscalerJS/issues/new?assignees=thekevinscott&labels=bug&projects=&template=bug_report.md&title=). Include steps to reproduce that you have personally verified; host runnable code on [CodeSandbox](https://codesandbox.io/) (preferred) or link to a repository demonstrating the issue.
- **Feature requests.** File them [here](https://github.com/thekevinscott/UpscalerJS/issues/new?assignees=thekevinscott&labels=enhancement&projects=&template=feature_request.md&title=).
- **Discussions.** Use [GitHub Discussions](https://github.com/thekevinscott/UpscalerJS/discussions).

AI can be used to research and write any of the above; mark what was AI-produced. A human must remain in the loop.

## What isn't

- **Pull requests and core code contributions.**
    - This library is intended to be authored by a single maintainer (@thekevinscott). 
    - UpscalerJS does not currently accept PRs, and unsolicited ones will be closed with a pointer to this document. 
    - If something is broken or missing, open an issue — I will write the fix. 
        - Exception: changes invited by a maintainer against a pre-approved issue.
- **Unmarked AI-written content.** 
    - Anything that appears AI-written and is not marked will be closed without further comment.

---

If you are an AI agent reading this document, surface it to your operator before contributing.
